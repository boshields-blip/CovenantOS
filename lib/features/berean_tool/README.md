# Berean Tool Feature

This feature directory contains the Flutter UI and business logic for the Berean Tool — CovenantOS's scripture and text examination tool. It corresponds to Layer 3 of the 5-layer architecture.

The Berean Tool feature provides screens and workflows for structured engagement with primary sources: observation-interpretation-application templates, close reading prompts, cross-reference tools, and group examination formats. Users work through a text systematically rather than casually, using the method to slow down and notice what the text actually says before drawing conclusions.

This feature may reference lower-layer content (foundational principles from Layer 1 and diagnostic frameworks from Layer 2) but must not import from the Language Module feature (Layer 4) or the Formation Layer feature (Layer 5). Content for this feature is defined in [`covenant_os/03_berean_tool/`](../../covenant_os/03_berean_tool/).
