# Covenant Forum Feature

This feature directory contains the Flutter UI and business logic for the Covenant Forum — the community and group surfaces that support formation practices in CovenantOS.

The Covenant Forum feature provides the screens and workflows for formation groups: creating and joining groups, viewing group formation history, facilitating group sessions of Come to the Table and Harvest and Hymn, and maintaining shared formation records. It is a cross-cutting feature that draws on the Formation Layer and the Language Module to present formation practices in a community context.

This feature is distinct from the individual-facing Formation Layer feature in that it focuses on the relational and communal dimension of formation rather than the practice content itself. Forum and group session data will be stored in Supabase (see [`docs/SUPABASE.md`](../../docs/SUPABASE.md)).
