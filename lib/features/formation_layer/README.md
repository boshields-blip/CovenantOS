# Formation Layer Feature

This feature directory contains the Flutter UI and business logic for the Formation Layer — CovenantOS's embodied practices layer. It corresponds to Layer 5 of the 5-layer architecture and is the topmost layer in the system.

The Formation Layer feature provides screens, guides, and rhythm tools for the two primary formation practices: **Come to the Table** and **Harvest and Hymn**. It includes facilitation guides, practice session structures, and community rhythm templates. This feature draws on all four layers below it and is the only feature permitted to import from any other feature layer.

As the Formation Layer is the culmination of the full CovenantOS stack, its UI surfaces the content and tools defined in the lower layers in a unified, practice-oriented experience. Content for this feature is defined in [`covenant_os/05_formation_layer/`](../../covenant_os/05_formation_layer/).
