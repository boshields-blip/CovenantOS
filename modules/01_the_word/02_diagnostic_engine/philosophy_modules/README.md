## How to use these modules

Each module follows the same seven-category order so it can be compared cleanly against other modules and against the covenantal philosophy. The purpose is not caricature but legibility. Most real teachers and traditions are shaped by mixed inheritances, not by one pure philosophy.

## Reading posture

Many teachers and traditions influenced by these patterns are sincere and well-intentioned. These modules diagnose formative tendencies, not personal motives.
