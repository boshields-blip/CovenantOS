# CovenantOS Content Tree

> A markdown-first content tree for CovenantOS's 5-layer formation architecture.

This directory is the canonical home for CovenantOS's layer content: foundational principles, diagnostic structures, Berean material, language formation, and embodied practices. The Flutter app in `lib/` presents and consumes this content, but the product ownership and boundary rules live in the top-level architecture docs.

## What lives here

CovenantOS is organized into five integrated layers:

1. **Foundational Layer** — the covenantal philosophy that supplies the governing frame
2. **Diagnostic Layer** — a seven-category engine for examining rival philosophies and distortions
3. **Berean Tool** — a teacher/pastor diagnostic that applies the engine to real-world influences
4. **Language Module** — the bridge that exposes how language carries philosophy and reshapes imagination
5. **Formation Layer** — the re-formation pathway that turns diagnosis into embodied renewal

## Intended posture

This content tree assumes a tone that is truthful, gentle, precise, and covenantal. It is designed to produce clarity without hostility, discernment without division, and formation without fear. Where diagnosis names distortions, the aim is not condemnation but repentance, reordering, and hope.

## What this content tree is for

This tree preserves CovenantOS's core formation content in a form that can evolve alongside the application. It gives the product a canonical vocabulary, consistent category order, draft schemas, and a navigable documentation structure that remains independent from PlumbLineOS and CommunityOS operational concerns.
