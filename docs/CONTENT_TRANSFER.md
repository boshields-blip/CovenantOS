# Content Transfer

**Status:** Draft | **Owner:** @boshields-blip | **Last updated:** 2026-07-31

---

## Purpose

This is the canonical transfer tracker for moving legacy CovenantOS content into the CovenantOS 2.0 module structure. It tracks what comes from the PlumbLineOS-era `covenant_os/` tree, where it lands inside `modules/01_the_word/`, and what net-new content still needs to be authored for the other modules.

---

## Transfer boundary

Only the markdown-first philosophical and formational content transfers into the target module structure. **No Supabase schemas, Flutter feature code, forum code, membership code, onboarding flows, or formation-group runtime records transfer into CovenantOS 2.0.**
